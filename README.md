# Учёба УБСТ2503

Личный учебный календарь: расписание из ЛК МТУСИ, задания и сроки из LMS, дедлайны и важное из чата группы в Telegram.
Сайт статический (`docs/`, GitHub Pages), данные лежат в `docs/data.enc.json` зашифрованными (AES-GCM, ключ из пароля по PBKDF2): без пароля их не прочитать.

## Как это работает

1. `collector/collect.mjs` открывает без окна Edge с отдельным профилем (`.profile/`), где выполнен вход, и забирает:
   - ЛК: `/api/timetable/get` (расписание группы);
   - LMS: AJAX Moodle (курсы, календарь, статусы заданий);
   - Telegram Web: историю форума группы.
2. `collector/build.mjs` сводит всё в один JSON: ищет дедлайны в чате (фразы «до 25 числа», «до 01.12»), подключает ссылки на пары и шифрует результат.
3. `collector/update.ps1` выполняет оба шага, коммитит и пушит, если данные изменились. Его запускает Планировщик задач Windows.

## Команды

```powershell
node collector/collect.mjs --login               # войти (ЛК — с галочкой «Запомнить меня»); окно закроется само
node collector/collect.mjs --login --only=lk,lms # перелогиниться только в ЛК/LMS
node collector/collect.mjs                       # собрать данные
node collector/build.mjs --plain --force         # собрать сайт (+ data/data.json для отладки)
powershell -File collector/update.ps1            # полный цикл с публикацией
```

- Пароль сайта лежит в `.site-password` (в git не попадает). Чтобы сменить, отредактируйте файл и запустите `build.mjs --force`.
- Ручные дедлайны добавляются в `data/manual.json`: `[{"id":"m1","title":"...","due":"2026-12-01T23:59+03:00","subject":"elec"}]`.
- Предметы, их цвета и темы чата настраиваются в `config.json`.
- Если в логе `data/update.log` появилось «нет входа», выполните `--login` ещё раз.
